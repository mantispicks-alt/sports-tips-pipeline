# Sports Tips Pipeline

Astro static site + Cloudflare Worker pipeline for aggregating football betting
signals from multiple tipster sources, running consensus, and publishing verified
picks with tracked results.

## Stack

- **Frontend**: Astro 5 + Tailwind, deploys static to Cloudflare Pages
- **Backend**: Cloudflare Worker (cron) + D1 database
- **CI**: GitHub Actions runs full ingest/settle every 2h (dispatched by Worker)
- **Data sources**: api-football, The Odds API, Highlightly, tipster site scrapers,
  Telegram channels, football-data.org

## Local dev

```bash
npm install
cp .env.example .env         # fill in brand + API keys
cp .dev.vars.example .dev.vars  # server-side secrets for wrangler dev
npm run dev                  # Astro dev server
npm run refresh:all          # run the full pipeline once locally
```

## Deploy

- **Site**: pushed to `master` → Cloudflare Pages builds `dist/` and deploys
- **Worker**: `npx wrangler deploy`
- **Pipeline**: dispatched every 2h by the Worker's cron; runs on GitHub Actions

## Structure

- `src/` — Astro site (pages, components, layouts)
- `src/content/tips/*.md` — published picks (regenerated by the pipeline)
- `src/lib/aggregation/` — consensus engine (tipster ingest, dedup, band assignment)
- `scripts/` — pipeline scripts (scrapers, generators, settlement)
- `worker/` — Cloudflare Worker source (cron + read API)
- `db/schema.sql` — D1 schema
- `.github/workflows/pipeline.yml` — 2h ingest+settle+deploy loop

## Brand

Every brand-identifying string (name, domain, email, worker URL) reads from
`PUBLIC_BRAND_*` env vars. The tracked source is generic — set the real values
in `.env` locally and in the deploy platform's env config for prod.
